قبل دمج/إصدار: يلزم نجاح Windows CI واختبارات rollback، وفحص صور الواجهة، ومراجعة رقم الإصدار وملاحظاته عند طلب إصدار. لا يُقدّم بناء Mono كحزمة Windows نهائية.

## نتائج التحقق

- نجح scripts/test-mono.sh مع فرض C# 5: 269 تحققًا، منها 34 فحصًا جديدًا للأعطال المكتشفة.
- نجحت اختبارات سلوك الواجهة المحلية ومحاكاة أحجامها.
- نجح بناء Windows الأصلي واختبار ترتيب RTL والقفل والحفظ والسجل، ومحاكاة حجم الخط والواجهة عند 125% و150% و200% مع التحقق من محاذاة الحقول وبقاء الجداول قابلة للعرض.
