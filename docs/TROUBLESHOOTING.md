# التشخيص وحل المشكلات

## ملفات التشخيص

افتحي تبويب «السجل» ثم «فتح السجل» للوصول إلى مجلد بيانات الحساب. هذه الملفات محلية وقد تحتوي بيانات تشغيل؛ أرسلي الأسطر المتعلقة بالخطأ فقط بعد إخفاء أي معلومات خاصة.

| الملف | المحتوى |
| --- | --- |
| `bridge.log` و`bridge.log.1` | القراءة وأخطاء القناة الأساسية؛ تدوير عند2MiB |
| `background.log` | تشخيص القناة الخلفية دون عرضه في الواجهة؛ يعاد إنشاؤه بعد تجاوز2MiB |
| `last-error.txt` | آخر رد HTTP فاشل من النظام الأساسي |
| `last-error-returns.txt` | آخر رد HTTP فاشل من الوجهة الثانية |
| `response.txt` / `response-returns.txt` | ردود لم تطابق إقرار النجاح المعروف |
| `settings.json` | إعدادات الحساب ورموز مشفرة؛ لا ترفعيه إلى Git |

هذه الملفات لا تضمن الاحتفاظ بكل تاريخ التشغيل. بعضها يستبدل آخر قيمة وبعضها يدوّر. لا تعتمد عليها كسجل محاسبي للأوزان، فالبرنامج ليس أرشيف عمليات.

## منفذ يفتح ثم يغلق

اقرئي نوع الاستثناء ورسالة الخطأ. `UnauthorizedAccessException` قد يدل على برنامج آخر يمسك المنفذ أو صلاحياته. `IOException` قد يشير إلى الوصلة أو التعريف. `MissingMethodException` الذي ظهر سابقًا كان خطأ توافق بناء في تحليل النص، وليس دليلًا على عطل الكابل؛ أصلح في0.9.2 باختيار Split(char[]) صراحة.

لا تغيري السرعة والتكافؤ عشوائيًا، ولا تفترضي أن إعادة فتح المنفذ تثبت استقرار القراءة. قارني إعدادات COM مع النسخة التي عملت بالفعل. لا تحذفي ملف الإعدادات لتجربة عمياء.

## بانتظار الوزن أو إطار غير مستقر

يتطلب المحلل CR أو LF لإغلاق الرسالة. الرسائل الجزئية تنتظر الجزء التالي. `ST,GS, 0,kg` صالح، بينما `US,GS,120,kg` غير مستقر ويُرفض عمدًا. لا تحوّل US إلى ST داخل البرنامج لإظهار رقم؛ يلزم فهم نمط خرج الجهاز إن كان لا يرسل ST مطلقًا.

## الأساسي يعمل والثاني لا يعمل

القناتان مستقلتان؛ راجعي background.log وآخر خطأ القناة الثانية.401 يدل على المصادقة،422 على توقيت العينة،409 على عينة متأخرة. أصلح رفض السالب في مشروع الموقع وليس بتغيير إشارة الوزن في العميل. لا تستبدلي رمز القناة الأولى بالثانية.

## تم الإرسال لكن الموقع لم يتغير

اكتملت كتابة الجسم، لكن هذا لا يثبت قبول الخادم. راجعي last-error والوجهة والشركة والمصادقة.302 إلى login ليس نجاح API، وHTTP200 مع HTML ليس إقرار حفظ. ثبات رقم الموقع قد يعني آخر قيمة مقبولة، ولا يثبت أن كل محاولة وصلت.

## تشفير الرموز بعد نقل الجهاز

DPAPI/CurrentUser مرتبط ببيئة الحساب. ملف الإعدادات المنقول لا يكفي لاسترجاع رمز الجهاز السابق. أعيدي التهيئة عبر ملف خاص مصرح به؛ لا تكتبي مفاتيح داخل المصدر أو ترفعيها كملف دعم عام.
