# واجهة قبان الغد — 0.14.0

البرنامج أداة عمل عربية لعرض الوزن وتشغيل القبان. تظهر الوظائف اليومية أولًا، وتبقى إعدادات الجهاز والسجلات في تبويبات واضحة.

- أرضية بيضاء، نص كحلي #1C2C3D، ولون بترولي #196969 للإجراء الأساسي والتبويب المحدد. الحدود رمادية خفيفة والألوان الدلالية للحالة فقط.
- شاشة وزن مدمجة 640×320 عند 100%، مع رقم بارز ووحدة «كغ» صغيرة مستقلة، وشرطة انتظار عند غياب القراءة. لا يُعرض صفر وهمي.
- تنقل نصي بخط سفلي، وأزرار تشغيل وإيقاف بحجم معتدل، وحالة نصية مع نقطة لونية لا تشبه الأزرار.
- جميع حقول الإعدادات ظاهرة في عمودين عند المقاس المعتاد، وعناوينها فوقها. تتكدس المجموعتان مع التمرير عند ضيق الشاشة، وتبقى إجراءات الحفظ والتشخيص في الأسفل.
- جدول سجل واحد، مع تبديل بين القراءات والأحداث. بحث واضح وتصفية للأحداث ومتابعة اختيارية، وتحديد ونسخ الصفوف.
- حوارات مدمجة ومتسقة لكلمة المرور والإصدار والتشخيص والعنوان ورسائل التأكيد والخطأ.
- Segoe UI المتاح في Windows، ونوافذ ومحاذاة RTL، وقيم COM والعناوين والأرقام LTR للحفاظ على وضوح الإشارة السالبة.
- إعلان System DPI awareness في manifest لتفادي تمديد صورة البرنامج وضبابية النصوص عند بدء التشغيل على شاشة مكبرة. لا تُضاف واجهات برمجية تحتاج Windows أو .NET أحدث؛ الانتقال بين شاشتين بمقياسين مختلفين يخضع لسلوك System DPI التقليدي.

التعديل بصري ويحافظ على القراءة والإرسال والإعدادات والتحديث و.NET Framework 4.5.1. تختبر صور Windows وتكبير الواجهة آليًا؛ يلزم تقييم بصري على شاشات التشغيل الفعلية كذلك.
