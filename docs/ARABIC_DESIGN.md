# الهوية البصرية العربية — 0.13.0

اختار المالك المظهر الفاتح بالكحلي والبترولي. يطبق التصميم على شاشة الوزن والإعدادات والسجلات وكلمة المرور والتحديث والتشخيص وتحرير العنوان ورسائل التأكيد والأخطاء.

- الخلفية #F3F7FA، والبطاقات بيضاء، والنص الأساسي كحلي #182B40، والإجراء الأساسي بترولي #006F6D.
- خط Segoe UI الداعم للعربية، مع أحجام متدرجة للعناوين والقيم والنصوص الثانوية. الخطوط متاحة مع Windows ولا تحتاج تنزيلًا.
- اتجاه RTL للنوافذ والعناوين والتنقل والإجراءات، وLTR لقيم COM والعناوين والأرقام والإطارات التقنية منعًا لالتباس الإشارة السالبة.
- أزرار موحدة بحالات المرور والضغط والتعطيل والتركيز، وحقول ذات حدود تركيز وخطأ، ومؤشر حالة نصي غير تفاعلي بألوان دلالية هادئة.
- عناوين فوق حقول الإدخال، وبطاقات إعدادات متجاورة تتكدس رأسيًا عند ضيق العرض أو تكبير الخط.
- جداول برؤوس عربية وصفوف متناوبة وتحديد واضح، وتفاصيل قابلة للالتفاف، وحالات فارغة وبحث بلا نتائج.
- عرض وحدة الوزن «كغ»، وترجمة أسماء التكافؤ في العرض مع الحفاظ على قيم None/Even/Odd/Mark/Space في الإعدادات.
- رسائل تأكيد عربية صريحة: «حفظ وتطبيق»، «تجاهل التغييرات»، «البقاء هنا»، و«تثبيت الآن» و«لاحقًا».

يحافظ التعديل على .NET الحالي وعقود القراءة والإرسال والإعدادات والتحديث. نوافذ اختيار الملفات التابعة لنظام Windows تتبع لغة النظام، مع عنوان ومرشح ملفات عربيين من التطبيق. فحوص تكبير الخط والواجهة لا تغني عن الاختبار على إصدارات Windows وأجهزة القبان الفعلية.
