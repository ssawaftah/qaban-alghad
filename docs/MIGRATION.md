# سجل نقل البرنامج إلى مستودع مستقل

## المصدر المرجعي

أساس العميل هو0.9.2 من المشروع السابق، بعد commit `88de936c523f68dd9315b7cad0c136f0992d6cd7` في مستودع `ssawaftah/qaban1`. أكد المستخدم عمل هذه النسخة ميدانيًا. تحديث قبول السالب في خادم المرتجعات هو `7ab68e0b54c913a3ae518313b127fcb4a95090ec`، ولا يدخل كود الموقع في هذا المستودع.

## ما نُقل وما تغيّر

| سابقًا | الآن |
| --- | --- |
| Bridge.cs يجمع البروتوكول والإعدادات وForm وProgram والاختبارات | ملفات مجال وإعدادات وواجهة وProgram واختبارات مستقلة |
| Interface.cs يجمع SurfacePanel والواجهة | UI/MainForm.Layout.cs وUI/Controls/SurfacePanel.cs |
| ResponseRules.cs يجمع أربع مسؤوليات | ResponseRules وDeliverySchedule وTransferFeedback وReadingPolicy |
| ملفات الاختبار تُضمّن داخل التطبيق | EXE اختبارات منفصل يشير إلى EXE التطبيق |
| نافذة تعرض رد الخادم | حالتا الميزان والإرسال فقط؛ التشخيص محفوظ |
| ملفات بناء يدوية متجاورة | scripts وpackaging وworkflow وSolution |

الاسم الظاهر وقفل النسخة الواحدة ومسار AppData ومفاتيح الإعدادات والتشفير وقواعد ST والإرسال الدوري لم تتغير. لا يوجد تغيير منشور على نسخة جهاز الشركة من مجرد إعداد هذا المصدر.

## التزامات النقل

- لا تحذف مصدر العميل القديم قبل رفع المشروع الجديد والتحقق من Windows واعتماد مرجع رسمي له.
- لا تنقل موقع المرتجعات أو قاعدة بياناته أو env أو مفاتيح Cloudflare إلى المستودع الجديد.
- لا ترفع ملفات EXE/DLL القديمة كبديل عن المصدر.
- لا تعلن أن0.9.3 إصدار إنتاجي أو أن التحديثات عبر الإنترنت تعمل قبل إتمام التحقق والتنفيذ.
- إذا استعمل المالك حساب GitHub جديدًا، حدّث روابط الإصدارات المستقبلية بعد اعتماد اسم المستودع النهائي فقط.

## نتائج التحقق

البنية المنظمة اجتازت13+97+56+29=195 تحققًا محليًا، مع تحميل التطبيق المبني من اختبارات منفصلة. ما زال يلزم تحقق Windows وواجهة عربية وCOM فعلي، والتحقق من workflow في المستودع الجديد بعد رفعه.
