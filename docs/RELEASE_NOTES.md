# قبان الغد 0.13.0

إعادة تصميم بصري عربية بالمظهر الفاتح والكحلي والبترولي الذي اختاره المالك.

- شاشة وزن ببطاقة بيضاء واضحة، وعنوان وهوية موحدة، ومؤشر حالة هادئ وأزرار تشغيل وإيقاف متناسقة.
- بطاقات إعدادات بعناوين فوق الحقول، وحدود تركيز وخطأ واضحة، وتكديس رأسي عند ضيق العرض أو تكبير الخط.
- سجلات برؤوس عربية وصفوف متناوبة وتحديد واضح ورسائل للحالات الفارغة والبحث بلا نتائج.
- تصميم موحد لنوافذ كلمة المرور والتحديث والتشخيص وتحرير العنوان ورسائل التأكيد والأخطاء.
- أزرار عربية صريحة لحفظ التعديلات أو تجاهلها أو البقاء، ولتثبيت التحديث أو تأجيله.
- عرض وحدة الوزن «كغ» وأسماء تكافؤ عربية، مع حفظ القيم التقنية القديمة كما هي.

نزّل الحزمة وفكّها كاملًا بعد إغلاق البرنامج السابق، أو حدّث من أيقونة «!» داخل البرنامج. بعد إعادة الفتح اضغط **تشغيل** لاستئناف القراءة والإرسال. تبقى إعدادات الحساب في AppData.

يبقى استهداف .NET Framework 4.5.1 وعقدا الإرسال والتشفير كما هي. لا تحتوي الحزمة العامة إعدادات فعلية أو رموزًا خاصة. يتحقق النشر من Windows وHTTP والحزمة والاستعادة والترقية عبر الإنترنت؛ اختبار أجهزة القبان وDPI/Narrator الفعليين مستقل عن المحاكاة الآلية. لا يدّعي الإصدار توقيع Authenticode فعليًا.
