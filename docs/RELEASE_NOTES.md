# قبان الغد 0.14.0

إعادة بناء الواجهة لتكون أبسط وأهدأ، بالمظهر الفاتح والكحلي والبترولي.

- شاشة وزن مدمجة: رقم واضح ووحدة صغيرة وحالة نصية، مع أزرار تشغيل وإيقاف معتدلة الحجم.
- تبويبات نصية، وإعدادات قصيرة تعرض الحقول معًا عند المقاس المعتاد.
- سجل بجدول واحد مع تبديل القراءات والأحداث والبحث والتصفية.
- نوافذ ورسائل أقصر ومتناسقة، وتحسين وضوح الرسم عند تكبير Windows.

نزّل الحزمة وفكّها كاملًا بعد إغلاق النسخة السابقة، أو حدّث من أيقونة «!» داخل البرنامج. بعد إعادة الفتح اضغط **تشغيل** لاستئناف القراءة والإرسال. تُحفظ إعداداتك الحالية في AppData.

لم يتغير منطق القبان أو الإرسال أو التشفير أو .NET Framework 4.5.1. الحزمة العامة خالية من الإعدادات الفعلية والرموز الخاصة. تحقق Windows والاختبارات المحلية لا يعوض اختبار جهاز القبان الفعلي. لا يتضمن الإصدار توقيع Authenticode فعليًا.
