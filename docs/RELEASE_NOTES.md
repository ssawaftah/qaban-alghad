# قبان الغد 0.11.5

- يتحقق البرنامج من وحدة القياس ويستأنف القراءة بعد الإطارات الطويلة.
- يحفظ الإعدادات دفعة واحدة ويستعيد آخر نسخة سليمة عند تلف الملف.
- يقرأ المنفذ ويكتب السجل في الخلفية ويحاول إعادة فتح المنفذ عند انقطاع البيانات.
- يعرض سبب توقف القراءة أو الإرسال. يتدرج تكرار المحاولة عند فشل الاتصال أو الكتابة.
- فحص الاتصال من الإعدادات، مع نسخ تشخيص مختصر ووقت آخر قراءة وإرسال.
- القناة الأساسية ترسل الوزن المستقر دوريًا دون انتظار رد.

حدّث من داخل البرنامج.
