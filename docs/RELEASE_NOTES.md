# قبان الغد 0.12.0

إصدار لتحسين الاعتمادية ووضوح الإعدادات والتشخيص وتجربة الاستخدام.

- الحفاظ على الرموز المشفرة عند تعذر فتحها، وإتاحة إصلاح الإعدادات ذات القيم الرقمية التالفة مع حفظ النسخة الاحتياطية الصالحة.
- حفظ التغييرات وتطبيقها أو تجاهلها قبل مغادرة الإعدادات، واستخدام الإعدادات المحفوظة عند التشغيل.
- قائمة COM قابلة للتحديث والإدخال اليدوي، ومؤشر حالة نصي بألوان واضحة، ومحاذاة أفضل للحقول.
- بحث وتصفية ومتابعة قابلة للإيقاف في السجل، وعرض صحيح للأوزان السالبة، وتمرير للجداول والتفاف الأدوات عند تكبير الخط.
- تسجيل وقت وصول العينة وسبب رفضها، وتشخيص واضح لإقرارات القناة الخلفية وتهيئتها دون كشف بيانات الربط.
- فصل جلسة قراءة المنفذ وكاتب السجل، وإغلاق منظم بمهلة محدودة لتفريغ الكتابات المعلقة.
- تقدم لتنزيل التحديث، ورسائل فشل مفهومة، وفحص آلي لقائمة ملفات الحزمة وبصماتها.

## التثبيت والتحديث

نزّل `QabanAlGhad-0.12.0.zip` وفكّه كاملًا في مجلد قابل للكتابة، ثم افتح `QabanAlGhad.exe`. أغلق النسخة السابقة قبل استبدال ملفاتها. يمكن أيضًا التحقق من التحديث من أيقونة «!» داخل البرنامج وتأكيد التثبيت. بعد إعادة فتح البرنامج اضغط **تشغيل** لاستئناف القراءة والإرسال.

تبقى إعدادات الحساب في `%LOCALAPPDATA%\WeighbridgeBridge`. لا تنقل ملف الإعدادات إلى حساب Windows مختلف وتتوقع فتح الرموز تلقائيًا؛ تحتاج الرموز عندئذ إلى إعادة تهيئة. لا تحتوي الحزمة العامة رموزًا أو إعدادات جهاز خاصة.

## التوافق والتحقق

يبقى استهداف .NET Framework 4.5.1 وعقدا الإرسال الدوري وتوافق الإعدادات كما هي. ترقية .NET مؤجلة إلى حين جرد إصدارات Windows الفعلية. مسار التوقيع الاختياري جاهز، لكن هذا الإصدار لا يدّعي وجود توقيع مستقل أو Authenticode فعلي.

يشمل التحقق الآلي Windows وبناء الحزمة وHTTP loopback والواجهة ومحاكاة الخط والأحجام 125% و150% و200% والتثبيت والاستعادة بعمليات فعلية. نجحت 269 حالة تحقق محلية قبل الإصدار. اختبار جهاز القبان والموقع الفعليين وDPI/Narrator الفعليين منفصل عن هذه الفحوص؛ لم تُرسل أوزان اختبار إلى الإنتاج.
