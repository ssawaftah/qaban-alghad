# قبان الغد 0.10.1

- فحص تحديثات البرنامج من GitHub تلقائيًا وعند الطلب.
- تنزيل حزمة الإصدار الرسمي والتحقق من digest والحجم قبل التثبيت.
- التثبيت بعد الموافقة وإيقاف القبان، مع أداة مستقلة ونسخة استعادة.
- إبقاء الإعدادات والرموز المشفرة خارج حزم التحديث.
- إزالة خانة رد الخادم من الواجهة، وبقاء تشخيص الردود في الملفات المحلية.

فك الحزمة كاملة في مجلد قابل للكتابة. على الجهاز نفسه وحساب Windows نفسه تُستخدم إعدادات النسخة السابقة تلقائيًا. لا تحذف AppData ولا تشغل النسخة القديمة بالتوازي. التحديثات لا تعني إعادة تفعيل إرسال الوزن تلقائيًا بعد إعادة التشغيل.

يتضمن هذا الإصدار اختبار ترقية عبر الإنترنت من الإصدار التمهيدي0.10.0 إلى أحدث حزمة منشورة على GitHub.
