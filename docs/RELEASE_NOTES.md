# قبان الغد 0.11.1

- تشغيل القراءة والإرسال معًا مباشرة، وإزالة خيار إرسال الوزن.
- إطار وزن بلا خلفية مميزة على اليمين، وأزرار تشغيل وإيقاف وحالة محلية على اليسار.
- الحالة خضراء فقط مع قراءة حديثة وكتابة طلب إرسال حديث؛ لا تعتمد على رد المستقبل.
- حماية دخول الإعدادات بكلمة المرور المحددة، وإعادة قفلها عند مغادرة الصفحة.
- تنظيم الإعدادات إلى بطاقتي الميزان وربط النظام.
- فصل سجل قراءات كل ثانية عن سجل الأحداث والأعطال، مع نسخ الصفوف وتدوير الملفات.

حدّث من الإعدادات. بعد إعادة الفتح اضغط تشغيل ليبدأ الإرسال. إعدادات الربط والتشفير محفوظة.

- ضبط محاذاة حقول الإعدادات، وتفادي وميض الحالة أثناء انتظار الرد، وتسجيل وصولات الميزان الجديدة فقط.
