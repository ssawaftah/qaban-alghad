# دليل استخدام قبان الغد 0.14

فك ضغط حزمة Windows كاملة داخل مجلد قابل للكتابة، ثم افتح `QabanAlGhad.exe`. لا تشغّل البرنامج من داخل ZIP. أغلق قارئ القبان القديم قبل بدء القراءة في النسخة الجديدة.

## الواجهة والتشغيل

تحتوي النافذة على ثلاثة تبويبات نصية من اليمين: **الوزن**، **السجل**، **الإعدادات**. يبدأ تبويب الوزن بمساحة عرض مدمجة 640×320 عند مقياس Windows ‏100%. تتسع النافذة للإعدادات والسجل، وتعود إلى الحجم المدمج عند الرجوع إلى الوزن. يتكيف الحجم مع مقياس الشاشة، ويمكن تكبير النافذة يدويًا.

يعرض تبويب **الوزن** الرقم ووحدة **كغ**، وتحته زرا **تشغيل** و**إيقاف** ونقطة الحالة مع وصفها. تظهر الشرطة **—** عند غياب قراءة صالحة وحديثة؛ وهي لا تعني أن الوزن صفر. يظهر رقم النسخة واسم المطوّر أسفل النافذة.

1. افتح **الإعدادات** وأدخل كلمة المرور عند طلبها.
2. تحقق من منفذ الميزان وسرعة الاتصال وبقية إعداداته، ثم عنوان الإرسال ورقم الشركة ورمز الوصول. احتفظ بالقيم المعتمدة لجهازك.
3. اضغط **حفظ وتطبيق** بعد أي تعديل، ثم افتح **الوزن** واضغط **تشغيل** لبدء القراءة والإرسال معًا.
4. انتظر وصول قراءة مستقرة وحديثة. يستمر الإرسال عند ثبات الرقم ما دام الميزان يرسل قراءات جديدة مستقرة.
5. اضغط **إيقاف** قبل تعديل الإعدادات أو فصل التوصيلات أو استبدال النسخة.

يعرض البرنامج الصفر والوزن السالب كما يصلان من الميزان. إذا توقف تدفق القراءات، يخفي الرقم القديم ويوقف إرساله حتى تصل قراءة حديثة.

## فهم الحالة

اقرأ وصف الحالة بجانب النقطة؛ الأخضر يدل على التشغيل والإرسال المحلي، والرمادي على التوقف، والكهرماني على الانتظار، والأحمر على مشكلة تحتاج مراجعة.

| النص الظاهر | المعنى والإجراء |
| --- | --- |
| متوقف | القراءة والإرسال متوقفان. اضغط **تشغيل** للبدء. |
| بانتظار القراءة | بدأ التشغيل، ولم تصل قراءة صالحة بعد. |
| بانتظار الإرسال | وصلت قراءة حديثة، ولم تكتمل محاولة الإرسال بعد. |
| يعمل ويرسل | توجد قراءة حديثة وكتابة إرسال حديثة إلى النظام الأساسي. |
| تعذر الإرسال | توجد قراءة، لكن محاولة الإرسال فشلت. افتح **السجل** و**تشخيص الاتصال**. |
| انقطع المنفذ | تحقق من الكابل والمنفذ؛ يحاول البرنامج استعادة الاتصال. |
| لا تصل قراءة | لم تعد القراءة الأخيرة حديثة. تحقق من بث الميزان. |
| قراءة غير مستقرة | انتظر استقرار الميزان. |
| قراءة غير صالحة / وحدة غير مدعومة / إطار أطول من الحد المسموح | راجع إعدادات الميزان والسجل. |
| راجع الإعدادات / راجع رمز النظام | افتح **الإعدادات**، وصحح القيم المطلوبة ثم احفظها. |
| متوقف بعد فشل التحديث | راجع رسالة الخطأ، ثم اضغط **تشغيل** بعد معالجة السبب. |

حالة **يعمل ويرسل** تؤكد الكتابة المحلية للطلب، ولا تؤكد وحدها حفظ الوزن لدى الموقع. عند اختلاف الوزن في الموقع، قارن وقت آخر قراءة وإرسال مع وقت تحديث الموقع.

## الإعدادات والسجل

تظهر علامة **\*** على **حفظ وتطبيق** عند وجود تعديلات لم تُحفظ. إذا حاولت مغادرة الإعدادات، اختر **حفظ وتطبيق** أو **تجاهل التغييرات** أو **البقاء هنا**. لتعديل عنوان إرسال طويل، انقر حقل العنوان مرتين، ثم اضغط **تطبيق** وأكمل بـ**حفظ وتطبيق**.

افتح **السجل**، ثم اختر **القراءات** أو **الأحداث** لعرض جدول واحد في كل مرة. استخدم خانة **بحث** للبحث، واختر **الأعطال فقط** عند عرض الأحداث. اضغط **متابعة تلقائية** لإيقاف انتقال الجدول إلى أحدث صف؛ يصبح النص **المتابعة متوقفة**، واضغطه مجددًا للاستئناف. حدد الصفوف واضغط **نسخ المحدد** لنسخها، أو **مجلد السجل** لفتح الملفات المحفوظة.

افتح **تشخيص الاتصال** من الإعدادات أو السجل لمراجعة المنافذ المتاحة وآخر قراءة وإرسال والأعطال المحلية. استخدم **نسخ التقرير** أو **حفظ التقرير** لمشاركته مع الدعم. فتح التشخيص لا يرسل طلب اختبار إلى النظام.

## التحديث وحفظ البيانات

اضغط **!** داخل الدائرة أعلى يسار النافذة لفتح **معلومات الإصدار والتحديث**، ثم اضغط **التحقق من التحديثات**. يظهر **جارٍ التحقق** أثناء الفحص، ثم **لديك أحدث إصدار** أو **تنزيل التحديث**. عند توفر تحديث، اضغط **تنزيل التحديث** وانتظر اكتمال التنزيل والتجهيز، ثم اختر **تثبيت الآن** أو **لاحقًا**. يتوقف القبان والإرسال عند تأكيد التثبيت ويُعاد فتح البرنامج؛ اضغط **تشغيل** لاستئنافه. إذا ظهر **تعذر التحقق**، راجع الاتصال بالإنترنت ثم أعد المحاولة.

تبقى إعدادات حساب Windows وسجلاته في `%LOCALAPPDATA%\WeighbridgeBridge` خارج مجلد البرنامج. لا تحذف هذا المجلد عند تحديث النسخة أو استبدالها. نقل البرنامج إلى حساب Windows أو جهاز آخر قد يتطلب إعادة إدخال رموز الوصول.
