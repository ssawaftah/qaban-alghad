# دليل استخدام قبان الغد

فكي ضغط حزمة Windows كاملة داخل مجلد قابل للكتابة، ثم افتحي `QabanAlGhad.exe`. لا تشغلي الملف من داخل ZIP. لا تشغلي البرنامج القديم بالتوازي معه لأن منفذ القبان لا يتحمل قارئين مستقلين.

## الاستخدام اليومي

1. افتحي الإعدادات وتأكدي من المنفذ والسرعة والتكافؤ وعنوان النظام ورقم الشركة.
2. افتح الإعدادات بكلمة المرور عند الحاجة، ثم اضغط «تشغيل» لبدء القراءة والإرسال معًا.
3. انتظري وصول الوزن من القبان؛ تُعرض القراءات المستقرة الحديثة فقط.
4. اضغطي «إيقاف» قبل تغيير الإعدادات أو إغلاق التوصيلات أو استبدال النسخة.

بدءًا من0.11 لا يوجد خيار إرسال منفصل أو وضع مراقبة. تشغيل يبدأ القراءة والإرسال إلى الوجهتين المجهزتين؛ إيقاف يوقفهما.

## معنى الحالات

| الحالة | معناها |
| --- | --- |
| متوقف | القراءة لم تبدأ أو أوقفت |
| بانتظار الوزن | المنفذ مفتوح، ولم تصل قراءة كاملة صالحة |
| متصل | وصلت قراءة مستقرة وحديثة |
| قراءة غير صالحة/لا توجد قراءة | الإطار غير مدعوم أو غير مستقر أو لم تعد العينة حديثة |
| مغلق | خيار الإرسال غير مفعّل |
| تم الإرسال | اكتملت كتابة جسم الطلب إلى الاتصال؛ لا تمثل بمفردها إثبات الحفظ بالخادم |
| لم يتم الاتصال | تعذر إرسال الطلب؛ راجعي السجل والوجهة |

إذا وقفت السيارة والوزن ثابت، يستمر الإرسال طالما الميزان يرسل قراءات جديدة مستقرة. توقف التدفق من الميزان يختلف عن ثبات الرقم، ويوقف إرسال العينة القديمة بعد انتهاء حداثتها.

الوزن السالب والصفر يعرضان كما يصلان. وجود سالب عند خلو القبان ليس شيئًا يصححه البرنامج بتغيير الرقم؛ معايرة الجهاز موضوع منفصل عن إرسال القراءة.

## حفظ الإعدادات والتحديث

تُحفظ الإعدادات لحساب Windows الحالي خارج مجلد البرنامج. لا تحذفي مجلد بيانات التطبيق عند تبديل نسخة. بعض بيانات الربط مشفرة للحساب والجهاز وتحتاج تهيئة جديدة عند نقلهما.

اضغط الأيقونة الدائرية «!» أعلى يسار النافذة، ثم اختر «التحقق من التحديثات» من نافذة معلومات الإصدار. إذا ظهر «يوجد تحديث»، اضغط عليه للتنزيل ثم أكد التثبيت وإعادة فتح البرنامج. عند ظهور «لا توجد تحديثات» يمكنك الضغط مجددًا لإعادة الفحص. اضغط «تشغيل» بعد إعادة الفتح لاستئناف القراءة والإرسال.

## الواجهة0.11

إطار الوزن بعرض النافذة أعلى صف التشغيل والإيقاف والحالة. قبل وصول القراءة يظهر kg دون رقم افتراضي. الأخضر يعني وصول قراءة حديثة وكتابة طلب إرسال أساسي حديثة، مع سماح بمهلة الطلب وثانيتين لتفادي الوميض؛ الأحمر يعني التوقف أو انتظار القراءة/الإرسال. لا يدل اللون على استلام الخادم أو حفظه. السجل يحتوي قائمتين مع إمكانية نسخ الصفوف المحددة.

## حجم النافذة

تبدأ شاشة الوزن بحجم مدمج640×304 عند مقياس100%. تتسع النافذة للإعدادات والسجل وتعود لحجم الوزن عند الرجوع إليه. يراعي الحجم مقياس Windows ومساحة الشاشة، ويمكن تكبيرها يدويًا عند الحاجة.

التبويبات من اليمين: الوزن، السجل، الإعدادات؛ يظهر التبويب الحالي بالأخضر. إطار الوزن أعلى صف التشغيل والإيقاف والحالة.
