# الإعدادات وحماية بيانات الربط

## مكان الإعدادات

```text
%LOCALAPPDATA%\WeighbridgeBridge\settings.json
```

هذا المسار متعمد للحفاظ على الأجهزة التي تستخدم 0.9.2. لا يوضع ملف إعدادات داخل مجلد الإصدار العام. السكربتات لا تنسخ بيانات AppData إلى `dist/`، ولا تحذفها عند البناء أو التغليف.

| الحقل | الافتراضي | الاستخدام |
| --- | --- | --- |
| `Port` | COM6 | اسم المنفذ؛ COM متبوع بأرقام |
| `Baud` | 9600 | سرعة الاتصال؛ تقيد الواجهة النطاق300..115200 |
| `DataBits` | 8 | بتات البيانات5..8 |
| `Parity` | None | None/Even/Odd/Mark/Space حسب إعداد الميزان |
| `Interval` | 1000 | حقل توافق؛ الواجهة تثبته1000ms، ومسار الإرسال الدوري يستخدم1000ms |
| `Freshness` | 3000 | عمر آخر قراءة صالحة، من1000 إلى30000ms |
| `Endpoint` | عنوان افتراضي للخدمة الأساسية | إعداد الجهاز المحفوظ هو المرجع الفعلي |
| `Company` | 1 | رقم الشركة كنص أرقام |
| `ResponseMarker` | فارغ | حقل تاريخي محفوظ؛ مسار القناتين الحالي يستخدم إقرارات محددة، لا يعتمد على هذا الحقل |
| `PrimaryTokenProtected` | فارغ | Bearer الأساسي مشفر، عند الحاجة |
| `ReturnsEndpoint` | عنوان Pages المعروف | عنوان القناة الخلفية، غير ظاهر في الواجهة |
| `ReturnsTokenProtected` | فارغ | Bearer الوجهة الخلفية مشفر |
| `ReturnsEnabled` | false في نموذج المصدر | حقل توافق؛ تشغيل القناتين حاليًا يتحكم به زر تشغيل، مع ضرورة صلاحية إعداد القناة |

`StopBits.One` و`Handshake.None` ثابتان، وDTR/RTS معطلان. لا تضف تبديلًا تلقائيًا لهذه القيم دون اختبار مع جهاز القبان نفسه.

## التكافؤ

التكافؤ Parity وسيلة لكشف بعض أخطاء نقل البتات على الاتصال التسلسلي، وليس كلمة مرور أو إعداد شبكة. يجب أن يطابق طرف الميزان. تغيير None إلى Even عشوائيًا قد يجعل الإطارات غير مقروءة. عند النقل من برامج أخرى انتبه إلى أن بعض ملفاتها تستخدم ترقيمًا خاصًا لا يطابق قيم enum في .NET.

## تشفير الرموز

يستخدم `LocalSecrets` حماية DPAPI بنطاق `CurrentUser`. السلسلة Base64 الناتجة ليست رمز API يمكن استعماله على جهاز آخر. تحتاج إعادة التهيئة عند تغيير حساب Windows أو الجهاز، ولا تنقل settings.json وحده وتفترض أن الرموز ستعمل.

قيمة entropy الحالية `QabanAlGhad local API credential v1` ليست سرًا ولا بديلًا عن DPAPI؛ هي ثابت توافق. تغييرها يجعل البيانات المشفرة السابقة غير قابلة للفتح. TryUnprotect يميّز غياب الرمز عن تعذر فتح رمز موجود. تحتفظ الواجهة بالقيمة المشفرة عند الحفظ حتى إدخال بديل؛ يتوقف بدء القناة الأساسية إذا تعذر فتح رمزها المحفوظ. القناة الخلفية لا تصبح Ready دون Bearer صالح، ويُسجل سبب التهيئة دون الرمز أو العنوان.

## استيراد تهيئة خاصة

الأداة `Bootstrap.Import` تبحث عن `Returns.setup.json` بجانب EXE. الملف خاص بالجهاز ويجب ألا يرفع إلى Git أو GitHub Releases. يوجد مثال غير صالح للإنتاج في `examples/Returns.setup.example.json`.

الاستيراد يتحقق من حجم4096 بايت كحد أقصى، والعنوان المحدد المسموح، ورمز غير فارغ بطول24 على الأقل. ثم يشفر الرمز، ويحفظه داخل AppData، ويحذف ملف التهيئة المستخرج بعد نجاح الحفظ. تبقى أي نسخة ZIP خاصة تحتوي الملف حساسة حتى بعد حذفه من مجلد التشغيل.

لا تعيد إدخال بيانات الوجهة الأساسية في ملف تهيئة القناة الثانية. الاستيراد مصمم ليحافظ على Endpoint وCompany للوجهة الأساسية. لا تعالج فشل الربط بإدراج رمز إنتاجي داخل كود C#.

## نقل الإعدادات في الإصدارات المستقبلية

قبل أي تغيير في schema: خذ نسخة احتياطية محلية، أضف قارئًا للحقول القديمة، اختبر ملفًا من نسخة عاملة، ثم احفظ الصيغة الجديدة بعد نجاح التحقق فقط. لا تغير مجلد AppData أو مفتاح DPAPI أو قفل النسخة الواحدة كجزء من تغيير تجميلي.

## قفل الإعدادات0.11

واجهة الإعدادات تتطلب كلمة المرور المحددة من المالك في كل دخول، مع إخفاء الإدخال وتأخير30 ثانية بعد5 أخطاء. يخزن المصدر مشتق PBKDF2 مملحًا، لا كلمة المرور الصريحة. هذا قفل للواجهة المحلية؛ ليس حاجزًا أمام مستخدم قادر على تعديل ملفات البرنامج أو AppData. لا يغيّر حماية رموز الربط الحالية أو مصادقة أي خادم.
