# قبان الغد — Qaban AlGhad

برنامج Windows يقرأ وزن القبان من منفذ تسلسلي واحد، ويعرضه بالعربية، ويرسل أحدث قراءة مستقرة إلى وجهتين مستقلتين في الخلفية. صُمّمت الواجهة لتكون بسيطة ومتمركزة، بخيار واحد للإرسال دون إظهار تفاصيل الوجهة الثانية.

هذا المستودع مخصص **لبرنامج القبان فقط**. موقع إدارة المرتجعات وخادمه وقاعدة بياناته تبقى في مشروعها المستقل. لا يحتوي هذا المشروع أي رمز API إنتاجي أو بيانات دخول، ولا يستبدل إعدادات الجهاز العاملة.

## التشغيل والبناء السريع

المستخدم النهائي يحتاج حزمة Windows مبنية، وليس تنزيل كود GitHub ثم فتح ملف C#. فك الحزمة كاملة، وشغل `QabanAlGhad.exe`، واضبط الوجهة الأساسية والمنفذ، ثم فعّل «إرسال الوزن» واضغط «تشغيل».

للمطور على Windows، من جذر المستودع:

```powershell
.\scripts\build.ps1
.\out\QabanAlGhad.Tests.exe --integration-test
.\scripts\package.ps1
```

السكربت الأول يبني التطبيق والاختبارات، ويشغّل فحوص البروتوكول والتوافق واستقلال قناتي الإرسال. اختبار `HttpListener` منفصل على Windows لأنه قد يحتاج URL ACL محليًا. لا تشغّل هذه الاختبارات على عناوين الإنتاج؛ الاختبارات الحالية تستخدم loopback وبيانات وهمية.

افتح `QabanAlGhad.sln` عند استخدام Visual Studio مع حزمة استهداف .NET Framework 4.5.1. السكربت المباشر يستخدم مترجم .NET Framework المثبت على Windows. تحقق Windows الأصلي شرط للإصدار، ونجاح Mono وحده لا يكفي.

## السلوك الذي يجب الحفاظ عليه

- قارئ منفذ واحد فقط. لا تفتح منفذًا لكل وجهة.
- محاولة إرسال دورية بفاصل ثانية لكل وجهة عند توفر قراءة مستقرة حديثة، حتى إذا لم تتغير القيمة. الطلبات البطيئة أو `Retry-After` قد تؤخر المحاولة؛ لا يوجد ضمان زمني لحظي عند تعطل الشبكة.
- كل وجهة لها طلبها ومهلتها وحالتها. تعطل الثانية لا يوقف الأولى، والعكس صحيح.
- لا يوجد طابور يعيد إرسال الأوزان القديمة. ترسل أحدث عينة عند إتاحة الطلب التالي.
- الصفر والسالب يحافظان على قيمتهما وإشارتهما. الإطار `US` غير المستقر لا يُرسل؛ الإطار `ST` المستقر يُقبل.
- تكرار القراءة نفسها يجدّد حداثتها. الحداثة تقيس آخر وصول، وليس آخر تغير بالقيمة.
- «تم الإرسال» تعني اكتمال كتابة جسم الطلب، وليست إثبات حفظه في الخادم. تشخيص أخطاء الخادم يبقى متاحًا رغم تبسيط الواجهة.
- لا تغير أسماء حقول الإعدادات أو مسارها أو entropy التشفير أثناء إعادة الترتيب.

## البيانات الخاصة

الإعدادات الفعلية تحت `%LOCALAPPDATA%\WeighbridgeBridge`؛ يحتوي بعضها أسرارًا مشفرة وسجلات تشغيل. لا ترفع هذا المجلد، ولا `Returns.setup.json`، ولا حزمة تهيئة خاصة إلى المستودع أو إلى إصدار عام. أمثلة `examples/` لا تحتوي مفاتيح صالحة.
